── FILE RESPONSIBILITIES ───────────────────────────────────────

  index.html
    · Page structure and layout markup
    · Loads sagefarm.css, Chart.js CDN, sagefarm.js (in that order)
    · Contains all inline HTML event handlers (oninput, onclick etc.)
    · WordPress: paste body content into Custom HTML block

  sagefarm.css
    · ALL styles scoped under #sf-planner-root
    · Uses CSS custom properties (--teal, --border, etc.) for theming
    · Safe to paste into WordPress Additional CSS if preferred
    · Responsive rules at bottom (@media max-width 480px)

  sagefarm.js
    · Wrapped in IIFE — no global namespace pollution
    · Key functions exposed on window object:
        window.sfCalcRet()       — recalculate retirement planner
        window.sfCalcSWP()       — recalculate SWP
        window.sfLiveComma()     — live Indian number formatting
        window.sfSlideToField()  — sync range slider → input
        window.sfAdjustCorpus()  — ±1 Cr corpus spinner
    · Chart instances: retCh (retirement), swpCh (SWP)
    · SF_R_ANNUAL = 0.22 (22% p.a. Sagefarm target — internal only)


── KEY CONSTANTS (sagefarm.js) ─────────────────────────────────

  SF_R_ANNUAL   = 0.22      Sagefarm target annual return (22%)
  Corpus slider = ₹1 Cr to ₹500 Cr  (10000000 to 5000000000)
  Years slider  = 1 to 50 years
  SWP loop cap  = 60000 months (~5000 years) for depletion calc

── TOOLTIP BEHAVIOUR ───────────────────────────────────────────

  · Triggered by CLICK on the bold "i" icon (not hover)
  · Auto-positions RIGHT of icon if space available, else LEFT
  · Click outside or click same icon again to dismiss
  · Styled: frosted glass, semi-transparent dark bg, blur backdrop


── WORDPRESS / CPANEL NOTES ────────────────────────────────────

  · All CSS scoped to #sf-planner-root — zero theme conflicts
  · No jQuery dependency
  · No WordPress hooks or shortcodes needed
  · Chart.js and fonts load from public CDNs (cloudflare, google)
  · If CDNs are blocked, download and host Chart.js locally:
      https://cdn.cloudflare.com/ajax/libs/Chart.js/4.4.1/chart.umd.js
      → upload to /wp-content/themes/your-theme/js/
      → update src in index.html accordingly
